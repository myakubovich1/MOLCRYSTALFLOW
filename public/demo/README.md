# Cytosine example data

The molecular input in `cytosine.xyz` and `sample_input.xyz` is neutral cytosine,
formula `C4H5N3O`, with all five hydrogens explicit.

Source: PubChem CID 597, 3D conformer `0000025500000001`. PubChem reports this
conformer as MMFF94-derived. The source atom coordinates and bond table are
recorded in `data/cytosine-example.json`.

`cytosine_crystals_z2.xyz` contains six structures generated by the MolCrystalFlow CCDC
v2 backend from that conformer. Every structure passed the backend's pre-optimization
geometry and clash checks, underwent ten rigid-body optimization steps, and was ranked
by UMA-s-1p2 energy. Each structure contains two 13-atom cytosine molecular bodies.
These automated checks do not establish physical stability or guarantee that every
periodic contact in the optimized coordinates is clash-free.

No static Z=4 gallery is published because no Z=4 candidate in the validation
runs passed the configured geometry and clash criteria. Z=4 remains available
for live generation.

Run `npm run validate:demo` after changing any example input or gallery file.
